KodaHosting Developer Handbook (DOCX, English, about 30 pages). Written for people who clone the repository, build the app, or write extensions.

Download the handbook (DOCX) Source code on GitHub

Opens in Word, LibreOffice, Google Docs or any other DOCX reader.

What is inside

  • What KodaHosting is - the device, connectivity and control planes, and the security model behind them.
  • Repository map - what lives where, and which parts talk to each other.
  • The public mirror - an honest list of what is deliberately missing (instance secrets, the Supabase project, tunnel and DNS credentials) and an eight step guide to running your own instance.
  • Building and running - requirements, Gradle commands, signing and the two traps that waste the most time.
  • The extension system - package format, the full manifest reference, permissions, the window.koda bridge, and every contribution type: language packs, themes (down to complete palettes with their own switches), settings entries, server tabs, UI tweaks and automations.
  • Customizing without extensions - translations and the checker that catches broken placeholders, theming, the four layout variants and how to avoid the classic crash, branding and the design rules.
  • Quality gates - the tests, checkers and simulations that run around a change.
  • Licensing and legal notes - GPL-3.0-only, third-party licenses, extension licensing and the public-repository rules.
